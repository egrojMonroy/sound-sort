Save to GitHub

The library is saved in this site's own repository. To save from this browser, paste a GitHub token once:

  1. Open GitHub → new fine-grained token.
  2. Under Repository access, choose Only select repositories and pick this repository.
  3. Under Permissions → Contents, choose Read and write.
  4. Create it and paste it below.

The token stays in this browser only. It is never saved in the repository.
